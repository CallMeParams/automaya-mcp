- `maya_list_node_types`: Concrete node types this Maya can create, filtered by substring, optionally (params: filter, plugin_only, include_inheritance, limit, offset)
- `maya_list_panels`: Every UI panel with type, visibility, camera for model panels, and which
- `maya_list_plugins`: Loaded plugins with versions, and optionally every loadable plugin found on (params: loaded_only, details)
- `maya_node_type_schema`: Every attribute of a node type with type, keyable flag, default, min/max, (params: node_type, max_attrs, keyable_only)
- `maya_option_vars`: Maya preference optionVars matching a prefix, with values. Read only. (params: prefix, limit, with_values)
- `maya_plugin_info`: Loaded state, version, path, vendor, commands and node types of one plugin. (params: name)
- `maya_search_docs`: Search an offline index of every cmds command name, flag list and synopsis (params: query, limit, rebuild)
- `maya_ui_tree`: Windows and panels, or the child controls of one window/layout/menu, as a (params: root, depth, max_nodes)
- `maya_workspace_info`: Current project root, file rules (scenes, images, sourceimages...), recent
